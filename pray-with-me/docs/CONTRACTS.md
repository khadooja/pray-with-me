# دليل الفريق 🤝

هلا والله! هذا الملف يشرح كيف نشتغل أربعتنا على نفس المشروع بدون ما نخرّب على بعض.
الفكرة ببساطة: كل وحدة لها **ملفات تملكها**، وفيه **عقود** (أشكال بيانات ثابتة) بين الأجزاء. طالما العقد ما تغيّر، كل وحدة تقدر تشتغل براحتها.

## التشغيل

تحتاجين Node.js 18 أو أحدث.

```bash
npm install
npm run dev          # افتحي http://localhost:5173/
npm test             # اختبارات المحاذاة
npm run build        # لازم ينجح قبل أي دمج
```

- `/?mock=1` ← وضع تجريبي: نتائج وهمية للوضعيات والتلاوة، بلا كاميرا ولا مايك ولا تحميل نماذج.
- `/labs/pose.html` ← مختبر الوضعيات (لضبط الأرقام).
- `/labs/speech.html` ← مختبر التلاوة (لقياس السرعة وتجربة النماذج).

الكاميرا والمايك يشتغلون بس على `localhost` أو `https`.

## العقود (لا تغيرونها بدون اتفاق الكل)

**الوضعيات:**
```js
evaluatePose(landmarks, stepId, aspect) // → { ok: boolean, issues: string[] }
```
- `issues` أكواد أخطاء مثل `"knees_bent"`، ونصوصها موجودة **بس** في `src/i18n/en.json`.

**التلاوة:**
```js
compareRecitation(transcript, reference) // → { complete, missing: string[], orderOk, matched, total }
```

**المحتوى:** كل خطوة في `fajr.json` فيها `id` و `type` (`guided` / `pose` / `speech`) و `title {ar, en}` و `instruction {en}` و `source`.
خطوة `pose` لازم يكون فيها `check` (`standing` / `ruku` / `sujood`)، وخطوة `speech` لازم يكون فيها `reference` و `transliteration` و `meaning` و `audio`.

## مين يملك وش

### 📖 المحتوى: ليان العصيمي
**ملفاتك:** `src/content/fajr.json` و `SOURCES.md` و `public/audio/`
- كمّلي الحقول اللي فيها `TODO` (المصادر، النطق، المعنى، الصوت)، والمحتوى كله لازم يتراجع شرعياً قبل الإطلاق.
- **لا تخترعين** أرقام أحاديث أو مصادر. إذا ما تعرفين المصدر خليه `TODO`.
- أي ملف صوت تضيفينه حطيه في `public/audio/` وسجّلي مصدره ورخصته في `SOURCES.md`. المسار في JSON يكون مثل `/audio/fatiha.mp3`.
- **لا تكسرين:** أسماء الحقول، و`id` الخطوات، وقيم `type` و `check`. النص المرجعي `reference` يكون بدون تشكيل.

### 🤖 الذكاء الاصطناعي: رهف الطير
**ملفاتك:** `src/pose/` و `src/speech/` و `src/pose/rules/thresholds.js`
- اضبطي الأرقام في `thresholds.js` باستخدام `/labs/pose.html`: جربي الوضعية الصحيحة والخاطئة وسجلي القيم.
- جربي النماذج وقيسي السرعة (خصوصاً على الجوال) في `/labs/speech.html`. تقدرين تبدلين النموذج من `ASR_MODEL_ID` في `src/config.js`.
- **لا تكسرين:** شكل العقدين فوق. وشغّلي `npm test` بعد أي تعديل على `align.js`.
- أي **كود خطأ جديد** تضيفينه (مثلاً `hands_not_on_knees`) لازم تبلغين فيه فريق الـ UX عشان يضيفون نصه في `en.json`.
- **السجود لازم ينجرب والجوال على الأرض على جنبك** (مو قدامك)، على بعد مترين تقريباً. هذا نفس الوضع اللي نطلبه من المستخدم في شاشة التجهيز، والقواعد كلها مبنية عليه (`pickSide` تختار جهة الجسم الأوضح للكاميرا).
- قاعدة السجود وأرقامها (`headBelowHipMargin`) **نسخة أولى بسيطة عن قصد**: تتحقق بس إن الرأس أوطى من الورك. اضبطيها بالمختبر قبل أي تطوير.

### تجربة المستخدم: ليان الزهراني
**ملفاتك:** `src/ui/style.css` و `src/i18n/en.json` و `src/ui/setup.js` و `src/ui/sound.js`
- اشتغلي على `/?mock=1` عشان تشوفين كل الحالات بدون كاميرا. في هذا الوضع تسمعين نغمة التلميح بعد ثانيتين ونغمة النجاح بعد ٥ ثواني تقريباً.
- **شاشة التجهيز** (تطلع قبل أول خطوة فيها كاميرا، ومن رابط "Setup help"): الرسمة SVG موجودة في `src/ui/setup.js` داخل دالة `illustration()`، ومشروحة بالتعليقات. تقدرين تبدلينها بالكامل.
- نصوص شاشة التجهيز كلها في `en.json` (المفاتيح اللي تبدأ بـ `setup_` و `test_sound` و `im_ready`).
- **النغمات** تتولد بالكود في `src/ui/sound.js` (بدون ملفات صوت). تقدرين تغيرين التردد والطول والارتفاع، والأرقام معلّمة بالتعليقات. خلي نغمة التلميح أنعم وأوطى من نغمة النجاح عشان يفرق بينهم المستخدم.
- مدة الانتظار قبل نغمة التلميح هي `HINT_AFTER_SECONDS` في `src/config.js`.
- الألوان كلها متغيرات في أعلى `style.css` (`--bg` و `--accent` ...).
- **لا تكسرين:** مفاتيح `en.json` (الكود يستخدمها بالاسم). تقدرين تغيرين النصوص براحتك، بس لا تحذفين مفتاح ولا تغيرين اسمه.
- لو حبيتي نضيف العربي: انسخي `en.json` إلى `ar.json` وترجمي القيم، والتعليمات موجودة في `src/i18n/index.js`.

### ⚙️ النظام: خديجة العمودي
**ملفاتك:** `src/main.js` و `src/config.js` و `src/progress/` و `vite.config.js` والنشر على Cloudflare Pages
- إعدادات Cloudflare Pages: أمر البناء `npm run build` ومجلد الإخراج `dist`.
- حد Cloudflare **25 ميغا لكل ملف**. ملف onnxruntime `.wasm` حجمه تقريباً 21–22 ميغا، فشيكي الأحجام بعد أي تحديث للمكتبات.
- أي صفحة HTML جديدة لازم تنضاف في `rollupOptions.input` داخل `vite.config.js`.
- **لا تكسرين:** نسخة MediaPipe لازم تبقى `0.10.14` بالضبط في `package.json` و `config.js`.

## قواعد git

- **`main` هو اللي ينشر** على Cloudflare، فلا أحد يدفع عليه مباشرة كود مو مجرب.
- كل وحدة تشتغل على فرعها: `content` و `ai` و `ux` (والنظام على `main` أو فرع `system`).
- **قبل أي دمج:** `npm run build` لازم ينجح، و `npm test` كذلك.
- **ممنوع منعاً باتاً ترفعون:**
  - أي مفاتيح أو ملفات `.env`
  - تسجيلات المستخدمين (صوت أو فيديو)، وهي مستثناة في `.gitignore` تحت `eval/recordings/`
  - صور التجارب
  - أوزان نموذج Whisper، لأنها تتحمل من Hugging Face وقت التشغيل
- لا تضيفون مكتبات جديدة بدون اتفاق الفريق.
