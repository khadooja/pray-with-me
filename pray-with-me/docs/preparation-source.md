# Preparation screen — "Before you pray" (قبل أن تصلي)

Six items shown on the screen before the prayer starts. None of these are checked by the
app — they are a reminder for the user to confirm for themselves. `scripts/build-content.mjs`
reads this file the same way it reads `content-source.md`, so nothing here is typed by hand
into `src/content/fajr.json`.

Approved by the content owner for all six items. The two conditions she attached (a wudu
link, an awrah detail line) are now met, so every item below is `Reviewed: yes`. Specialist
(Sharia) review is separate and still pending — see SOURCES.md.

### item: time
- Arabic title: دخول الوقت
- English title: Prayer time
- Text (English): The time for Fajr has started.
- Source: الدرر السنية، الموسوعة الفقهية: اشتراط دخول الوقت
- URL: https://dorar.net/feqhia/831
- Reviewed: yes
