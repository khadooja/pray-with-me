# نقطة البداية

هذا الملف يوثّق بشفافية **وش كان موجود قبل فترة التحدي**، و**وش انبنى خلال التحدي**،
عشان لجنة التحكيم تعرف بالضبط وش الشغل اللي تم أثناء الهاكاثون.

نقطة البداية محفوظة في git بالوسم **`v0-start`**:

```bash
git tag v0-start
git push origin v0-start
```

وللمقارنة بعدين: `git diff v0-start..main --stat`

## ما كان موجوداً قبل التحدي

1. **هيكل المشروع**: Vite 5 مع JavaScript عادي متعدد الصفحات (`index.html` وصفحتين مختبر)، وإعدادات البناء للنشر على Cloudflare Pages.
2. **العقود بين الوحدات مع نسخ تجريبية (mock)**:
   - `evaluatePose(landmarks, stepId, aspect) → { ok, issues }`
   - `compareRecitation(transcript, reference) → { complete, missing, orderOk, matched, total }`
   - وضع `?mock=1` يسمح بتجربة الواجهة كاملة بدون كاميرا أو مايك أو تحميل نماذج.
3. **صفحات المختبر**: `labs/pose.html` لضبط أرقام الوضعيات، و`labs/speech.html` لقياس سرعة التعرف على الكلام.
4. **قواعد أولية للوضعيات** (القيام والركوع والسجود) بأرقام مبدئية غير مضبوطة في `src/pose/rules/thresholds.js`.
5. **خوارزمية المحاذاة الأولية** للفاتحة (LCS مع تسامح بحرف واحد) مع اختبارات في `tests/align.test.mjs`.
6. **محتوى مسودّة** لركعة واحدة من الفجر في `src/content/fajr.json`، والمصادر كلها `TODO` وما تمت مراجعتها شرعياً.
7. واجهة بسيطة جداً (ثيم كحلي) والتوثيق (README و SOURCES و CONTRACTS).
